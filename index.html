Chat Order OCR

把聊天視窗中的訂單文字，快速整理成按姓名分組、可人工覆核的訂單名單。

前往 GitHub 專案

工具特色

保守解析支援 +1、＋2、一份、兩盒、3個等常見數量格式。
姓名分組依訂購人整理，保留原始品項與規格文字。
人工覆核OCR 或不明確內容會標示為需要確認，不自行猜測。

快速使用

將聊天內容保存成 messages.txt，在專案目錄執行：

python3 scripts/order_ocr_cli.py \
  --input messages.txt \
  --source text \
  --group-by person \
  --format json \
  --output orders.json

適用情境

適合水果團購、社群預購、LINE 或 Facebook 訊息整理等情境。出貨前請逐筆確認姓名、品項、價格、重量與數量。
